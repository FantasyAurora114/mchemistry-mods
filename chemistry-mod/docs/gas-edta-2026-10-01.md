## 钢瓶供气与本生灯

1. 放置甲烷钢瓶与本生灯。用输气管依次点钢瓶和本生灯，完成连接后消耗一根管。
2. 空手右键钢瓶开阀。空手点击本生灯底部旋钮（底部 3 像素范围）开启燃气。
3. 等管内空气排出、甲烷到达，再用打火石点燃。戴护目镜可查看甲烷缓冲余量与状态。
4. 空手点击灯体上部或潜行点击，切换进气环与蓝焰/黄焰；蓝焰有效加热功率更高。
5. 将容器放在灯上方或邻近铁架台。关闭燃气旋钮、甲烷不足时熄火。
6. 用剪刀或空手取回管线，返还对应的橡胶管/输气管；管内残余气体按现有断管机制逸出。

钢瓶开阀后自动向连接端供气，实际扣余量；接收端满或堵塞时保留管内气体并停供，关阀停止推进。未接管却开阀会逸气、扣余量。空钢瓶可在阀门关闭时接受现有气路送来的同种气体，不允许混入不同气体。

流量上限为每条连接 5 mL/tick，本生灯燃烧消耗 2 mL/tick。短管内部储量与流量分开结算，可以在一个 tick 内反复流过，避免短管供气不足而熄灭。未点燃且开燃气时，灯内甲烷会逐渐逸出。

燃烧式：CH₄ + 2O₂ → CO₂ + 2H₂O(g)。氧气首版取自环境，尾气未单独接管；燃烧热约 802 kJ/mol，蓝焰/黄焰捕获效率采用游戏参数 30%/15%，同一刻的热量预算由受热容器共享。蓝焰/黄焰的温度上限采用游戏参数 1200°C/600°C。管线碰撞修正改善下垂落地，不是完整软体碰撞模拟。

## EDTA

加入以下八种固体、对应溶液及试剂瓶/滴瓶外观：

| 试剂 | 采用的无水化学式 |
| --- | --- |
| EDTA 游离酸 | C₁₀H₁₆N₂O₈ |
| EDTA 二钠 | C₁₀H₁₄N₂Na₂O₈ |
| EDTA 四钠 | C₁₀H₁₂N₂Na₄O₈ |
| EDTA 钙二钠 | C₁₀H₁₂CaN₂Na₂O₈ |
| EDTA 镁二钠 | C₁₀H₁₂MgN₂Na₂O₈ |
| EDTA 铜二钠 | C₁₀H₁₂CuN₂Na₂O₈ |
| EDTA 亚铁二钠 | C₁₀H₁₂FeN₂Na₂O₈ |
| EDTA 铁钠 | C₁₀H₁₂FeN₂NaO₈ |

- 一份溶液物料账本派生配合状态；不会额外生成另一份试剂或重复质量。
- 按 1:1 计量求解 Ca²⁺、Mg²⁺、Cu²⁺、Fe²⁺、Fe³⁺ 与 EDTA 的竞争，包含四步质子解离，并同时求解铁—硫氰酸根竞争。
- 加酸可降低有效螯合；金属竞争取决于常数、酸度与加入量。足量 EDTA 可降低铁—硫氰酸根的红色比例，铜 EDTA 有蓝色反馈。
- 护目镜显示配合量与近似 pH；玻璃棒取样/pH 试纸使用同一套受支持体系的计算结果。
- 当前支持水、上述金属及氯化物/硝酸盐/硫酸盐、Na/K、强酸强碱、乙酸/乙酸盐、硫氰酸根；出现其他未支持水相组分时提示体系未完整建模，不给出 EDTA 精确平衡读数。
- 当前是 25°C 理想浓度模型。未建立完整离子活度、全部金属水解、配合与沉淀/氧化还原共同平衡、温度依赖及结晶水机制。
- 新 EDTA 溶解上限与库存浓度属于首版游戏参数，尚不是经标定的温度溶解度曲线；没有虚构溶解焓，暂按 0 处理。现有其他反应仍沿用原框架。
