# 沉淀平衡第一阶段：草酸钙扩展

## 已实现

沿用原有草酸钠、草酸钾、氯化钙和草酸钙物品，增加水中溶解后的物料份额及离子映射。两种草酸盐均可与氯化钙逐步生成白色草酸钙沉淀：

Na₂C₂O₄ + CaCl₂ → CaC₂O₄↓ + 2NaCl

K₂C₂O₄ + CaCl₂ → CaC₂O₄↓ + 2KCl

CaC₂O₄(s) ⇌ Ca²⁺(aq) + C₂O₄²⁻(aq)

平衡采用 25°C 的 Ksp = 2.3×10⁻⁹，来源：[UBC Chemistry 溶度积数据表](https://groups.chem.ubc.ca/courseware/pH/kspdata.html)。游戏当前使用 CaC₂O₄ 化学式，不区分结晶水形态。使用理想浓度近似，尚未计算活度或温度相关的 Ksp。

- 加水会降低离子浓度，使部分沉淀溶解；固体不足时可完全溶解。
- 增加氯化钙或草酸盐带来同离子效应，促进沉淀、抑制溶解。
- 沉淀、已溶物料均使用容器实际质量，不建立重复物料副本。每次平衡转移检查元素、质量和电荷守恒。
- 过滤保留固体，已溶物料随滤液转移；湿滤纸、漏斗待滤物和接收液保留真实份额。
- 无水时已溶份额返回固体。容器复制、漏斗拾取及保存兼容。
- 佩戴护目镜可见草酸钙状态、平衡式及 Q/Ksp。

## 原有反应兼容

湿润的受支持体系交由沉淀平衡处理，旧定时反应不重复生成沉淀。初始加入尚未溶解的盐也适用互斥。干燥盐的旧反应、草酸钙高温分解保留。

新增溶解标识兼容原有反应表：氯化钙、草酸钠、草酸钾即使已溶，也能被相应旧规则识别；反应完成时扣除实际液相物料。原有氯化钙与碳酸钠溶液生成碳酸钙的路径继续可用。

## 游戏内验收

1. 烧杯加入水、氯化钙与草酸钠；等待溶解和白色沉淀形成。草酸钾同样适用。
2. 加入水，观察护目镜沉淀平衡读数；通常只溶解少量沉淀，不会因少量水让大量固体全部消失。
3. 另取有沉淀的混合液加入氯化钙，观察平衡向沉淀方向移动。
4. 通过滤纸过滤。固体留在滤纸，接收瓶保留已溶份额。
5. 拾取并重新放置漏斗、保存并重新载入世界，确认物料保留。

## 当前边界与下一步

仅支持各体系指定的盐和水。混入酸碱、其他反应物或竞争沉淀时，不由这个独立 Ksp 适配器接管，保留现有反应路径。氯化银也采用相同的受支持体系范围检查，避免在酸或未知溶液中错误套用简单浓度模型。

氯化钙、草酸钠、草酸钾的初始溶解上限分别使用 80、3.7、30 g/100 g 水的游戏近似；这些是暂定的室温上限，各温度节点暂相同，不是已验证的温度曲线。未新增未经标定的溶解热参数。

下一步按路线推进酸碱平衡与滴定，再处理草酸多级解离和沉淀的酸碱耦合。之后统一热量，再扩展有机分层/合成、电化学与相平衡。
