## 氯化银体系

AgCl(s) ⇌ Ag⁺(aq) + Cl⁻(aq)

使用 25°C 的 Ksp = 1.6×10⁻¹⁰，理想稀溶液浓度近似。数据：
[OpenStax Chemistry 2e，附录 J](https://openstax.org/books/chemistry-2e/pages/j-solubility-products)。

目前支持硝酸银、氯化钠、氯化钾及相关硝酸盐、氯化银和水组成的体系。
- 可直接加入现有散装硝酸银和氯化钠/钾，在水中溶解后逐步生成白色沉淀。
- 增加氯化物可抑制氯化银溶解；加水稀释可使部分沉淀溶解。
- 纯水中氯化银溶解量非常小；普通瓶中的大量沉淀不会因少量加水全部消失。
- 有固体共存时接近饱和平衡。固体不足时可以完全溶解，液相不被强制设为饱和。
- 过滤保留真实固体，已溶解的离子随滤液转移；湿滤纸中的液体也保留。
- 过滤漏斗中的待滤物料和接收液持续处理相态/平衡。
- 不通过“添加水则向左”的硬编码决定平衡；使用总离子量、液体体积、Ksp 求解，再逐步向目标靠近。
- 中性盐份额是物料记账方式，溶液物种视图按真实份额展开为离子。每次沉淀事务校验元素、电荷与质量守恒；没有额外复制一份离子质量。
- 支持体系的旧沉淀定时规则和自动 AgCl 分解不与新平衡同时运行。
