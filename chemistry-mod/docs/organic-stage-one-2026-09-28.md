# 有机液体分层与基础分离：第一阶段

## 已加入
- 水—甲苯、水—四氯化碳的有限溶解与双液相。甲苯密度较小，通常上浮；四氯化碳较大，通常在下层。按各相实际质量/占用体积排序，水相内大量溶质也会影响密度。
- 水、乙醇（含现有75%/95%库存形式）、甲醇、丙酮、甘油、乙酸作为已知单相组合处理。存在有机不互溶溶剂和这些共溶剂时，不用二元近似猜测三元相图。
- 水相的可识别溶液物料留在水相；少量甲苯/四氯化碳按室温上限进入水相，其余成为有机相。固体原位保留，分层取液不会把沉淀一起吸走。
- 玻璃棒或已有搅拌路径使两相暂时分散，静置后恢复分层。分散期间取样包含两相的整体比例，不假装能吸到纯净的一层。
- 烧杯与烧瓶的通用实体内容渲染支持两个颜色区间；锥形瓶使用按原几何裁切的上层液体模型。六款现有烧杯和两款锥形瓶的物品模型也加入双层状态，各层颜色独立。外观约按5%容量档位绘制，真实物料和读数不受此档位限制。
- 护目镜显示上下层名称、体积和分散状态。普通实验提示沿用原有规则。

## 分层取液滴管
新增25 mL分层取液滴管，暂时沿用普通滴管模型与贴图。

- 合成：普通胶头滴管 + 玻璃。
- 主手拿取液滴管、副手拿容器，右键操作；也可以右键放置或挂载的容器。
- 空管普通右键吸取上层，潜行右键吸取下层，每次最多25 mL，在当前界面停止。
- 管内有液体时，普通右键向容器转入最多5 mL，潜行转入最多1 mL。倒空后才能再次吸取。
- 没有两层的已支持单相液体按整体比例取样；复杂未建模混合物暂不允许宣称选择一层。
- 不能从密封容器取液或向其加入；接收容器容量不足时只转移容得下的部分。
- 保存实际各物质克数、温度和液体状态，按实际转移量扣账，并携带显热。水的待汽化热量只随实际转移的水移动，不跟着取出的纯有机层走。

普通倒液、滴定与过滤仍沿用既有整体比例规则。选择上下层分离请使用本次专用取液工具。尚无新分液漏斗及其开阀分液动画。

玻璃棒蘸取分层液体时取上层0.05 mL，不再同时从两层扣量。明确不含水的甲苯、四氯化碳、无水乙醇、甲醇、丙酮或甘油样品使用pH试纸会标“不适用（非水样品）”。其余历史库存水溶液保留原有估计行为，避免因旧编码未单独保存水而误标成非水体系。

## 模型与科学范围
这是一项限定体系的室温游戏近似：使用NIOSH甲苯0.07 g/100mL水、四氯化碳0.05 g/100mL水数据，在水密度近似1 g/mL下按实际水质量分配；沿用现有密度0.87和1.59 g/mL。忽略水溶入有机相的少量份额、温度曲线、盐析、体积收缩、真实分散液动力学和非理想活度。有限溶解按当前物料即时计算，不声称完整液液平衡求解器。

来源：[NIOSH甲苯](https://www.cdc.gov/niosh/npg/npgd0619.html)、[NIOSH四氯化碳](https://www.cdc.gov/niosh/npg/npgd0107.html)、[表格单位说明](https://www.cdc.gov/niosh/npg/pgintrod.html)。

没有加入任意溶质的萃取分配系数、碘/溴萃取、有机合成动力学或蒸馏汽液平衡。多种有机不互溶溶剂、共溶剂及未知液体组合会保留原始物料并标为未建模。普通过滤漏斗和滴定管的液体仍使用已有单色外观，不能把它们视为双层显示已验收的仪器。

下一项建议做碘在指定溶剂间的分配与重复萃取，并配合用户后续分液漏斗模型，再接基础酯化/水解。
