# 温度计套管

使用下载目录的 `温度计套管.bbmodel`，源文件备份在 `work/thermometer_sleeve_sources/`。
原模型 11 个方块、256×256 贴图，UV 使用源项目 16 单位坐标。以 y=7.8 的下部凸缘作为磨口贴合面；不改原贴图。

## 使用

- 从仪器创造栏取出温度计套管，对准空闲磨口右键安装。
- 当前接入实体版仪器：磨口烧瓶、磨口锥形瓶、磨口平底烧瓶、三颈烧瓶的三个口、蒸馏头上口、未连接接收瓶的牛角管下口。普通非磨口容器不接受；已被塞子、蒸馏头或接收瓶占用的口不接受。
- 拿温度计右键套管，最多装一支。空手右键先取温度计，再次右键取套管；潜行空手右键同时取两件。
- 配戴护目镜查看装有温度计的套管可读温度，或拿另一支温度计右键读取。沿用现有容器温度；没有增加蒸汽与液体温度的独立模拟或测温滞后。
- 三颈侧口按 ±35° 随瓶身朝向旋转；套管及内部温度计一起对齐。F9 可查看套管选取框。
- 取走或破坏母仪器时，套管和温度计作为独立物品掉到原位置。单独拆套管返还背包，背包满则掉落。
- 保存原始 ItemStack，温度计自定义名称等数据保留。卸载区块不会拆除套管。旧的温度计直接插入蒸馏头/橡胶塞的方式继续兼容。

此版不新增合成配方；旧方块版支架/加热套内嵌的磨口容器未接入这套实体附件安装。

## 验证

31 项 GameTest 通过：包括三颈四向安装、口占用、普通口拒绝、磨口锥形瓶、温度计消耗/拆除/改名数据保存、母仪器删除掉落和区块卸载保留。客户端实际烘焙检查确认 66 个模型面全部使用原贴图。游戏世界内外观与多人操作尚未人工验收。
