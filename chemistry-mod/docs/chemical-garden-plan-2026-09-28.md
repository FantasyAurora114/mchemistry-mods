# 水中花园（化学花园）实现方案

本次提供设计方案，尚未加入此反应。已完成的下一开发阶段是有机液体分层与基础分离，见 organic-stage-one-2026-09-28.md。

## 实验目标
在烧杯内加入硅酸钠水溶液，投放铜盐或铁盐晶粒，观察盐粒表面成膜、膨胀破膜、彩色管状结构向上延伸并分枝。液面、浓度、盐粒量和搅拌影响生长，重载世界后结构保持原状。

研究中的管壁可包含非晶硅胶以及金属氢氧化物/氧化物。沉淀膜分隔内外液体，渗透作用使内部吸水并升压，破膜后流出的液体在界面继续沉淀，形成管状结构；浮力影响生长方向。不能把所有体系统一描述成一种纯金属硅酸盐。

参考：[Barge 等，From Chemical Gardens to Chemobrionics](https://doi.org/10.1021/acs.chemrev.5b00014)；[铁基硅胶花园扩散与沉淀研究](https://pubmed.ncbi.nlm.nih.gov/27397509/)。

## 第一阶段：两种盐、可见且有物料约束的生长
- 补硅酸钠固体与溶液数据、溶解记录，以及缺少的沉淀物种。先支持铜盐蓝绿结构、铁(III)盐棕黄结构；具体颜色作为游戏显示参数，不宣称固定的真实晶体颜色。
- 盐粒分别记录投放位置、粒径、剩余质量、膜厚、内部溶液与生长状态。不会把加入的一份盐复制成多个完整盐粒。
- 状态流程：溶解 → 表面沉淀膜 → 吸水膨胀 → 局部破膜 → 管道伸长 → 重新成膜/分枝 → 原料不足时停止。
- 使用有限速率和阈值近似渗透与浮力，不在首版运行完整流体力学。密度、浓度差和膜强度决定趋势；速度及阈值明确属于游戏参数。
- 每次沉积扣除真实反应物，产物仍在容器的固体账本中。生长结构仅引用其沉积质量，不再额外增加物料。结构外形的孔隙空间与真实固体占用体积区分。
- 不按动画帧数直接生出固定质量，不随机生成额外试剂。结构长度和管径必须受已沉积质量约束。

若首版采用简化产物记账，可使用以下配平的近似路径，但不能宣称它们准确描述复杂膜的全部组成：

```
Na2SiO3 + CuSO4 + H2O → Cu(OH)2 + SiO2 + Na2SO4
3Na2SiO3 + 2FeCl3 + 3H2O → 2Fe(OH)3 + 3SiO2 + 6NaCl
```

后续按所选水合盐修正晶体配方与结晶水，避免无水盐和水合盐共用错误摩尔质量；首版未知沉淀热不新增猜测值。

## 第二阶段：外观与操作
- 在现有烧杯模型内动态绘制低面数空心管段、端部鼓包和分枝。复用玻璃透明层、液位和沉淀颜色，无需先做一个固定“植物”模型，也无需图像生成。
- 根据容器尺寸映射位置，结构不穿出玻璃壁；生长前沿主要限制在液面以下。第一版不模拟伸出液面的复杂干燥结构。
- 肉眼能看见实际结构变化；护目镜提供膜状态、剩余盐量与停止原因，沿用现有实验反馈门槛。
- 普通玻璃棒搅拌可折断结构，折断部分变为容器内对应沉淀，不丢失产物。过滤可回收碎片；整株取出、干燥收藏可后续加入。
- 拾取烧杯、放入柜子与世界保存都保留结构。杯中存在结构时，倒液默认保留附着沉淀；彻底清空会清除结构，避免空杯残留。

## 第三阶段：扩展机制
在上述玩法验证后加入其他金属盐、晶粒大小、硅酸钠浓度及温度影响。再接入已有沉淀、溶解和热量机制，研究不同膜的扩散与渗透行为；涉及硅酸解离、pH 梯度和活度时需扩展当前限定体系求解器。

它与本次液体分层共享容器局部状态、真实物料、密度、保存及显示基础，但渗透膜内部液体不是有机相，不能直接当作两层溶剂处理。

## 验收实验
1. 同样浓度，增加盐粒质量不会凭空增加产物；元素、质量和电荷守恒。
2. 加清水改变浓度和生长趋势，而不是立即复制一套新结构。
3. 无硅酸钠时不生成“花园”；原料耗尽、液体移走或结构受破坏时正确停长。
4. 搅拌、过滤、倒液和拾取后没有产物丢失或重复。
5. 同一随机种子与同一物料重载后保留枝条位置和状态。
6. 烧杯内多株结构有数量及管段上限，避免长时间运行无限增加渲染与存档负担。

建议第一版只支持摆放后的烧杯进行主动生长；手持时保存状态，物品栏显示简化轮廓，避免多个背包容器同时进行复杂几何模拟。具体生长速度与外观可以在模型预览后调整。
