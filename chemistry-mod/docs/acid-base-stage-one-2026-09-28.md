# 酸碱平衡与滴定第一阶段

## 已加入

1. 盐酸、硝酸与氢氧化钠/钾的水中中和，按照实际克数和化学计量生成盐及水。
2. 乙酸与氢氧化钠/钾中和，生成乙酸盐；支持乙酸—乙酸根缓冲体系，以及乙酸盐的水解。
3. 乙酸钠、乙酸钾加入水中的溶解份额和离子映射，已溶份额在无水时恢复为固体。
4. 护目镜显示动态 pH，潜行详细检查显示水的离子积和乙酸解离信息。
5. 玻璃棒取样与 pH 试纸使用同一计算结果，取样仍实际扣除最多 0.05 mL 液体，检测消耗样品及一张试纸。
6. 胶头滴管向容器添加时，普通右键最多 5 mL，潜行右键最多 1 mL；余量不足时只加入实际余量。满容器不扣滴管液体。手持、副手、放置容器、铁架台相关路径共用添加规则。

这是现有滴管的逐毫升滴定原型，尚未加入专用滴定管或逐滴 0.05 mL 的滴定设备。玻璃棒的 0.05 mL 取样与滴管的 1 mL 添加是不同操作。

## 计算与物料

使用 25°C、理想浓度近似：Kw = 1.00×10⁻¹⁴，乙酸 Ka = 1.80×10⁻⁵。

参考：[OpenStax 酸碱强度与解离](https://openstax.org/books/chemistry-2e/pages/14-3-relative-strengths-of-acids-and-bases)、[OpenStax 酸碱滴定](https://openstax.org/books/chemistry-2e/pages/14-7-acid-base-titrations)。

根据强酸、强碱、乙酸与乙酸盐的实际总量，联立水的自电离、弱酸物料平衡和电荷平衡求 pH。在极稀溶液、缓冲区、当量点和过量加入后使用同一个计算过程，不用固定的“可逆反应转化一半”替代解离。

- 强酸强碱等量中和后接近中性。
- 乙酸滴定的半当量点接近 pKa；当量点因乙酸根水解呈碱性。
- 乙酸和乙酸盐共存时可抵抗少量酸碱加入；稀释不按强酸的方式强制改变 pH。
- 中和实际消耗酸和碱，生成盐和水，不重复运行旧中和定时配方；小于旧反应门槛的微量加入也能中和。
- 已溶乙酸盐在加入强酸后可转为乙酸及相应氯化物/硝酸盐。
- 实际物料事务和派生离子视图均检查元素、质量及电荷守恒。弱酸解离、盐水解和水自电离只改变派生物种，不另造一份质量库存。
- 现有试剂的浓稀标识和库存换算继续沿用；酸的记录克数按对应化学物料解释，并未把库存瓶统一标定为指定 mol/L。加入水后才能使用本阶段水溶液模型。

## 游戏内操作

### 强酸强碱

先给烧杯加入水，再加入盐酸或硝酸。将装有氢氧化钠溶液的滴管向容器添加，接近终点时使用潜行右键逐毫升加入。佩戴护目镜查看 pH；继续加入过量碱后，pH 应转为碱性。KOH 同样支持。

滴管仍存储原有单一试剂标识和体积，不是任意混合液的完整微量取样容器。玻璃棒样品保留实际混合液各成分的比例。

### 乙酸滴定和缓冲

水中加入乙酸，逐步加入 NaOH/KOH。观察酸性、缓冲区、当量点的碱性和碱过量阶段。也可在乙酸水溶液中加入现有乙酸钠或乙酸钾，等待溶解后观察少量酸碱加入与稀释的影响。

### pH 试纸

潜行用玻璃棒蘸取容器液体，再用 pH 试纸检测。支持的体系显示近似整数 pH；试纸颜色仍限制在 0–14 的显示范围。取样后保留当时的读数，之后再改变原容器不会改动已取样记录。

未支持的混合液保留旧目录估计，试纸标明“估计（未建模体系）”。反应分析提示及试纸结果消息遵守护目镜反馈开关；已测试纸本身保留其读数和颜色。

## 当前边界

本阶段只接管水、HCl/HNO3、NaOH/KOH、乙酸、Na/K 乙酸盐及相应中性氯化物/硝酸盐组成的体系。酸的原有浓稀变体兼容，但高浓度活度尚未计算。

含碳酸盐、硫酸/磷酸、氨/铵、其他金属、其他弱酸或竞争沉淀时，不声称提供本阶段完整平衡计算。原有反应路径保留。草酸多级解离、草酸钙的酸碱耦合仍待后续扩展。

乙酸钠、乙酸钾的溶解上限暂用 100 g/100 g 水的游戏上限，各温度节点暂同值，不是实测曲线。本次未添加未经标定的乙酸盐溶解热。

中和热、统一能量账本、温度依赖的 Kw/Ka、活度修正、指示剂滴定终点、实验记录曲线及专用滴定管尚未实装。下一步按既定路线处理统一热量，再推进有机分层与合成、电化学和相平衡。
