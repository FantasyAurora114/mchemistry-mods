# 试剂柜

## 使用

在“仪器”创造物品栏取得高试剂柜或矮试剂柜。

- 高柜占两格高度，5 层，每层 3 格；矮柜占一格高度，3 层，每层 3 格。
- 右键打开柜门和储物界面。退出界面后门保持打开；潜行右键关门。
- 每格一件，界面从上到下对应柜内从上到下的层板，从正面看左右一致。
- 可存窄口试剂瓶、广口固体瓶、滴瓶、各规格烧杯、普通/磨口锥形瓶、量筒。开口状态与内容物不影响存放资格。
- 支持 Shift 点击转移。取出后保留原物品的成分、温度、名称与其他数据。
- 生存模式拆除高柜任意一半，掉落一个柜子及所有内容物；创造模式只掉内容物。矮柜同理。移动方块替换也会释放库存。
- 其他玩家关门后，已打开的柜子界面会失效并关闭。关闭界面本身不触发关门。
- 柜内使用现有物品模型显示；尚无三维模型的物品仍采用原有物品外观。
- 本次没有新增合成配方，也没有增加柜内反应或温控功能。

## 实现

`ReagentCabinetBlock` 负责方向、两格配对与开门状态；两个方块类型共享 `ReagentCabinetBlockEntity`。高柜仅下半格保存库存，上半格交互转发到下半格。破坏掉落统一使用 `preRemoveSideEffects`，避免玩家破坏和邻居更新重复结算。活塞不能推动柜子。

`ReagentCabinetMenu` 使用两种已注册菜单类型区分 15/9 格，并在槽位与容器入口限制放入物品。原样保存 ItemStack，客户端通过原版容器同步和方块实体更新同步。

`ReagentCabinetRenderer` 使用主体、左门、右门三个独立模型；门围绕源模型的铰链转动，约 0.5 秒打开。层板高度来自源模型。按物品模型包围盒等比缩放，避免大型量筒或锥形瓶穿过层板。

源模型与贴图保留在 `work/reagent_cabinet_sources/`；运行 `python3 work/import_reagent_cabinets.py` 可重建资源。保留源 JSON 的 0–16 UV、百叶窗旋转与玻璃透明度。
