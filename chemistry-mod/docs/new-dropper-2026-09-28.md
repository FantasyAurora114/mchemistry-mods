# 新胶头滴管与滴瓶

采用桌面“胶头滴管新.bbmodel”11 个部件与原始内嵌贴图，保留蓝色胶头。普通、棕色滴管及分层取液滴管共用新外形；棕色滴瓶继续使用棕色瓶身。

滴瓶由当前细口瓶瓶身、开孔瓶塞与新胶头滴管组合。移除原玻璃塞手柄，将塞芯和塞身拆成四片，留下供滴管玻璃管穿过的孔。滴管末端伸入瓶内，胶头位于瓶塞上方。75 种试剂沿用现有文字标签及液体色，物品栏液位沿用 20 档水纹模型。容量保持 100 mL。

取下瓶塞滴管后显示打开的瓶口，插回后恢复完整外观。空瓶保留，取液仍扣实际余量；每支滴管最多 25 mL。取出的滴管带开孔瓶塞。铁架台瓶塞中的安装滴管也同步采用新模型，管尖向瓶内延伸。

操作沿用原机制：右键取下滴管；另一手持该瓶塞滴管时右键瓶身即可插回。普通滴管和分层取液滴管的取液功能未调整。

验证：79/79 GameTests 通过，其中已有取下、插回、25 mL 扣量和守恒测试加入打开/完整模型状态检查；最终 build 成功。185 个相关 JSON 与引用的模型、贴图检查通过。未完成客户端游戏内视觉验收。
