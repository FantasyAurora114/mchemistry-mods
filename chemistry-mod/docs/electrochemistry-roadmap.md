# MChemistry 电化学模型清单与实施方案

2026-09-26；此文件为设计提案，尚未实施电化学设备或回路。

## 1. 已有基础与缺口

- 桌面已存在 `bench_power_supply.bbmodel`：79 个元素、64×64 贴图、两组电压/电流旋钮、两块显示屏、两组红黑输出与绿色接地端。电源模型不必重做；需导入、标注端点，显示屏数字由游戏绘制。首版只启用 CH1，CH2 与绿色接地、USB、交流输入先保持外观，避免把接地端当负极。
- 已有 electrical_wire 物品和像素图，但没有世界连接实体、电路拓扑或导电行为。线体可程序生成，不必画整段固定形状电线。
- 现有烧杯、液位、溶解度、温度、集气瓶、玻璃管和橡胶管可复用。现有气路代码只作连接/渲染经验参考，导线拥有独立端点、存档和网络，不直接混用气体管道状态。
- 溶液已有物种视图、元素/电荷守恒检查和铁—硫氰酸根配合平衡，但不是完整电化学引擎。SpeciesCatalog 有 Cu²⁺/铜和 H⁺/OH⁻，缺 Zn²⁺/锌、氢氧气的完整质量映射；现有硫酸锌试剂也不能仅凭名字视为已能参与离子结算。

## 2. 模型制作清单

| 优先级 | 模型 | 要求与用途 |
|---|---|---|
| 第一批 | 金属片电极 | 一套几何，铜、锌、铁等不同材质；上端接线区、下端浸液区分开；首版先铜，锌用于第二阶段原电池 |
| 第一批 | 双电极绝缘固定架 | 跨在烧杯口或装在铁架台上；两个独立夹持点，电极可单独装卸并调节插入深度；主体绝缘，不把两极短接 |
| 第一批配套 | 香蕉插头、鳄鱼夹 | 可以做成导线两端的小部件；鳄鱼夹上下颚分组，红黑护套用材质变体；首版也可先由代码生成简单形状 |
| 第二批 | U 形盐桥 | 两端插入两只烧杯；玻璃、内部电解质/凝胶、端部多孔塞分组；固定间距首版即可，后续再支持不同跨度 |
| 第二批 | 电压表/万用表 | 两个明确的测量端点，独立显示屏和模式旋钮；测电压高阻并联，不能将测量行为当作大电流负载 |
| 第二批 | 小灯泡或负载电阻 | 验证原电池真正带负载供电；与仅测开路电压区分。先选一种即可 |
| 第三批 | 石墨棒电极 | 单独几何，顶部接线帽；给惰性电极近似实验使用，适用范围由反应数据限定，不能在所有条件下永久无损 |
| 第三批 | 两极分开的集气罩 | 每个电极上方单独罩体、各自导气口，复用现有软管和集气瓶；防止默认把氢氧气混到同一个出口 |
| 后续 | 分隔电解槽与隔膜 | 左右两室、隔板、各室电极接口及独立液面；用于浓差、膜迁移、盐水电解等 |

**最小可用批次：已有电源 + 铜电极 + 双电极固定架 + 已有烧杯与电线。** 先做这一批即可跑通电解，不必等待完整电解槽或霍夫曼电解器。

## 3. 给模型的接口约定

1. 以现有 100 mL 烧杯为装配参照，保持工程目前的 16 单位 = 1 方块。放入同一 Blockbench 场景核对比例。
2. 电极分为 `terminal`、`insulator`、`active_body`，可选独立 `deposit` 显示层；电极消耗只缩减浸液活性区，接线端不跟着缩进杯内。镀层由程序生成或缩放一层模型，无须手画几十种质量状态。
3. 明确接线点 `wire_port`、安装点 `mount`、活性段上下端 `active_top/active_bottom`。用 locator 或配套坐标说明；定位点不导出为可见方块。
4. 固定架标出 `electrode_left/right` 和两侧夹持旋转轴。正负极由电路决定，不把阳极/阴极永久写死在某一边。
5. 电源两通道分别命名 CH1/CH2，标出各红黑端口，旋钮轴心和屏幕平面。绿色接地端不能与黑色负极共用同一个逻辑节点。
6. 盐桥标出两端浸入点；集气罩标出电极中心和导气口。透明玻璃、液体和不透明部件分组，保留内嵌贴图。

## 4. 开发路线

### 阶段 A：铜电极—硫酸铜的可见质量转移

玩家把两片铜电极插入同一烧杯，分别接电源 CH1 红黑端，设置电压和限流后开机。电极需浸液且互不接触，导线不能直接接在玻璃杯上。

首版限定一台电源、一个电解池、一个串联回路；限制电流并显示断路、短路、离液、阳极耗尽等具体原因。先用明确标识的创造实验电源验证，再接有限能源供电；生存版通过能量余额或 FE 适配器限制输出，FE→J 换算是游戏参数。

铜阳极：Cu → Cu²⁺ + 2e⁻；铜阴极：Cu²⁺ + 2e⁻ → Cu。

两端共享同一电量 Q = IΔt，转移铜的物质的量为 Q/(2F)。理想的首版模型中阳极损失等于阴极增量、溶液铜总量近似不变；不加入本来没有发生的析气或水量凭空变化。这与 RSC 的铜电极定量电解实验对应：
https://edu.rsc.org/experiments/quantitative-electrolysis-of-aqueous-copperii-sulfate/1883.article

验收：每次反应、电極质量、能量与显示状态一并提交；微量余数保存；断线/离液/拆除即时停止；读档不复制镀层；多人重复点击不重复扣取。

### 阶段 B：锌—铜原电池

两只已有烧杯分别装 Zn/ZnSO₄ 与 Cu/CuSO₄，盐桥连接两室，导线连接电极、电压表或负载。

Zn → Zn²⁺ + 2e⁻；Cu²⁺ + 2e⁻ → Cu。锌片减重，铜片增重；接负载后由化学变化提供电能。断盐桥后停止持续供电。盐桥传递离子以维持各室电荷平衡，不把盐桥当作电子导线，也不能让两杯溶液瞬间合并。

先采用有限实验配对、标准电势与简化内阻；开路只显示电压，理想电压表近似不耗料。以后加入浓度、温度、极化与能斯特方程。RSC 的教学装置采用金属/盐溶液、盐桥与电压表：
https://edu.rsc.org/download?ac=515964

原电池的阳极为负极、电解池的阳极为正极；共同点是阳极发生氧化、阴极发生还原。代码应保存“氧化/还原角色”和实际电势，不能固定“红色=阳极”。

### 阶段 C：惰性电极电解与独立集气

先做硫酸铜溶液在合适惰性电极上的镀铜/析氧，再做明确支持电解质条件下的水电解。氢氧气按反应物摩尔数分别出账，支持 2:1 的物质的量关系和不同气路收集；不将旧 mL 体积直接当质量。

采用明确的半反应适用范围、浓度与介质限制，再逐步加入过电位和竞争反应；石墨作为教学近似电极时明确允许的体系。水溶液与熔融物使用不同规则，避免 NaOH/KOH 水溶液析出钠或钾。

液面随真正失去的水/溶质/气体变化，电极离液停止；热量进入现有温度系统，同时避免把同一份电能完整计入化学能和发热两遍。

### 阶段 D：配合电镀、浓差电池、膜与腐蚀

补铜氨/银氨等配合物后，放电条件读取游离金属离子，沉积扣总金属，再重新求配合平衡；不会同时扣一次自由离子、又扣一次配合物而双重消耗。之后加入隔膜室、电镀工件、可充电体系和腐蚀。

## 5. 必须先补的代码基础

- 独立电线端点与回路图：接线、拆线、区块卸载重建；同一电源或电极不得被重复结算。
- 持久化的电极基材与镀层质量；电极表面材质取决于最外层镀层，避免镀铜铁片仍永久表现为裸铁。
- 半反应数据及成对原子事务：同时覆盖液体、基材、沉积、气体、电量与能量。
- 通用溶液写回：当前 `SolutionSpecies.snapshot` 是计算视图，不能靠修改它保存反应。阶段 A 可用现有总量验证铜转移；进入改变电解液组成的阶段前，扩展唯一的持久化组分结构并适配旧配方/读档，使 H⁺、OH⁻、反离子和迁移量都能保留。禁止另存一份重复可消费的离子库存。
- 盐桥的有限电解质、离子迁移及两室电荷守恒；与单杯电解的约束不同。
- 温度、溶解度、液色和液位全部从同一物质状态计算，不由动画反向生成化学物质。

建议先批准阶段 A；模型制作顺序为：**铜电极 → 双电极固定架 → 线端接头 → 锌电极材质 → 盐桥 → 电压表与负载 → 石墨电极与集气罩**。
