# 水中花园、萃取与有机反应、原电池和盐桥

更新日期：2026-10-01。适用于 MChemistry 的 Minecraft 1.21.10 / NeoForge 版本。

## 1. 水中花园

### 操作

1. 使用任意烧杯，加入约 200 mL 水、10 g 硅酸钠，等待溶解。
2. 用药匙加入少量无水硫酸铜或氯化铁晶体，把开口烧杯放在实验台上。
3. 静置观察：先表面溶解，随后形成沉淀膜、膨胀并破膜，长出带分枝的管状沉淀。铜盐为蓝绿色，铁盐为棕色。护目镜显示阶段与段数。
4. 玻璃棒搅拌会打碎结构，沉淀质量仍保留，可过滤回收。清空烧杯后才能重新建立完整花园。

新增硅酸钠固体、溶液及其试剂瓶资源。硅酸钠溶解度目前使用游戏参数，并非完整温度曲线。

### 机制

- 仅放置的烧杯推进生长，拿起后暂停，已有结构随物品保存。
- 膜、膨胀和管壁的沉淀来自实际反应。晶体、硅酸钠和水逐次扣除；管形只是沉淀的显示方式，不额外生成物质。
- 每种盐最多 32 段；反应物、液位和密封状态限制继续生长。低液位暂停，既有结构保留。
- 材料被移走或反应消耗后，对应结构随剩余沉淀减少；清空不留下管形。
- 当前一杯分别显示一组铜盐、铁盐结构，未模拟任意数量独立晶核、连续流体或定量渗透压。

采用守恒的简化总式：

- Na₂SiO₃ + CuSO₄ + H₂O → Cu(OH)₂↓ + SiO₂↓ + Na₂SO₄
- 3 Na₂SiO₃ + 2 FeCl₃ + 3 H₂O → 2 Fe(OH)₃↓ + 3 SiO₂↓ + 6 NaCl

这里的 SiO₂ 表示简化的硅质沉积，并未另设水合凝胶组成。首先使用上述简单体系；酸、络合剂和其它盐的完整耦合留待后续。

## 2. 分液漏斗萃取

### 操作

1. 将少量碘加入水，再加入甲苯、四氯化碳或足量乙酸乙酯。
2. 分液漏斗装在铁架台上。点顶端取塞后加液，封塞后潜行点顶端摇匀，静置恢复分层。
3. 取下玻璃塞并安装接收瓶，打开旋塞排出下层，到界面自动停止。换瓶后再排其它层。
4. 可用分层滴管分别取上层、下层；用新鲜小份溶剂重复萃取，可进一步降低水相碘残留。

与水分层时，甲苯、乙酸乙酯通常位于上层，四氯化碳通常在下层；实际代码按两层组成和密度排序。乙酸乙酯加入过少时会全溶于水，不形成第二层。水相和乙酸乙酯碘溶液显示棕色，甲苯/四氯化碳相显示紫色；颜色随碘浓度变化，护目镜以 mg 显示碘余量。

### 机制与范围

- 碘以真实质量记录在水相或有机相中，转移液层时相应溶质一起扣除、加入。
- 使用 `K = c有机 / c水`，通过实际两相体积求分配量。溶解固体碘时还有有限溶解上限。
- 首版游戏分配参数：甲苯 80、四氯化碳 85、乙酸乙酯 20。这些用于玩法校准，**不是实验测得的精确常数**。
- 液相采用粗略二元模型，包含有机溶剂在水中的有限溶解；尚未处理双向互溶、碘离子/三碘离子平衡和温度依赖。
- 乙醇等共溶剂或多个有机溶剂存在时提示复杂体系，不套用该二元分层模型。
- 仍保留已有的密封、混合分散、固体阻塞、满瓶保护以及层间自动停止。

## 3. 有机反应

### 可逆乙酸乙酯体系

乙酸 + 乙醇 ⇌ 乙酸乙酯 + 水

- 混合乙酸和乙醇，加入少量盐酸、稀硫酸或浓硫酸，保持 45°C 以上。
- 少水、乙酸/乙醇充足时生成酯和水；酯与水充足时发生酸催化逆向水解。
- 催化剂不在此反应中扣除。每一步按有限实际摩尔数计算，并检查元素、质量和电荷守恒。
- 移走生成物或增加反应物会改变下一步反应方向。浓硫酸暂作为酸催化剂，未另行模拟吸水脱水。
- 当前平衡表达采用摩尔量近似，`K = 4`，反应速率为游戏参数；尚未加入活度、严格酸性依赖及反应热。
- 替换了原先单向的乙酸—乙醇旧反应，避免两个引擎同时扣料。其它既有有机反应仍沿用原有机制。

### 碱性水解

乙酸乙酯 + NaOH → 乙酸钠 + 乙醇

乙酸乙酯 + KOH → 乙酸钾 + 乙醇

碱会实际消耗，耗尽即停止；升温提高简化反应速率。反应生成的乙醇等组分使体系超出二元分层范围时，需要先进一步处理再选择性分液。

## 4. 锌铜原电池与盐桥

### 新仪器

| 物品 | 用途 |
|---|---|
| 原电池半电池杯 | 500 mL 可取放容器，安装单个电极网 |
| 锌电极网 | 初始 10 g 金属余量，可拆卸 |
| 盐桥 | 独立离子连接，初始 1 g KNO₃，最长 3 格 |
| 实验电阻 | 100 Ω 测试负载 |
| 实验电压表 | 高阻测量回路，不消耗反应物 |

新增硝酸锌固体、硝酸锌/硫酸锌溶液及其试剂瓶资源。物品栏图标直接绘制；半电池杯复用烧杯模型，其余世界外观使用轻量几何绘制，日后可替换专用模型。

### 单对连接

1. 放两只半电池杯。锌侧装锌网和锌盐溶液；铜侧装铜网和硫酸铜溶液。可以先在其它容器配好溶液，再手持容器点击半电池杯转移，每次最多 25 mL。
2. 每侧至少有 25 mL 液体，且锌侧存在锌盐、铜侧存在铜盐。首版支持水与这些对应盐的简单体系。
3. 手持盐桥依次点击两杯建立离子通路；潜行取消第一端。
4. 用现有电线连：铜电极 → 电阻红端 → 电阻黑端 → 锌电极。接电压表时同理。
5. 单对标准电动势约 1.10 V。开路和高阻电压测量均无反应物消耗。

盐桥不是电线，也不算电子回路的一段。电压表目前使用两个接线柱形成高阻测量路径，不支持复杂并联网络；与负载混接时整个串联路径按测量开路处理。

### 串联与已有电解器

每对锌—铜半电池先各接一条盐桥，再将第一对铜端连接下一对锌端，最后一对铜端连接电解器正端，电解器负端返回第一对锌端。多对同方向串联增加电动势。

首版与原有霍夫曼电解器、高水槽电解及其电线图共用负载检查和实际电荷。电压不足、气体满管、低液位、反接、耗料或盐桥断开均会停止供电；有一段回路缺失时不能运行。

### 材料账本

- 锌氧化：Zn → Zn²⁺ + 2e⁻；铜还原：Cu²⁺ + 2e⁻ → Cu。
- 每份反应量 n 统一按 Q = 2Fn 结算，锌网减少、铜网镀层增加，负载使用同一份电荷。
- 盐桥消耗 2n 摩尔 KNO₃，将硝酸根计入锌侧、钾离子计入铜侧。
- 中性存储账本表现为锌侧生成硝酸锌，铜侧硫酸铜减少并生成硫酸钾；并非把盐桥物质凭空删除。
- 同一游戏刻即使多只设备轮流更新，也只结算一次完整回路。
- 剪刀拆盐桥/电线；半电池杯潜行空手先拆网，再取杯。网的剩余金属和镀层、盐桥余量、容器内容物都保留。

当前采用每对 20 Ω 的游戏内阻、0.2 A 供电上限及固定标准电动势。尚未加入浓度电池、完整能斯特方程、反向充电、任意金属电对和并联电路。
