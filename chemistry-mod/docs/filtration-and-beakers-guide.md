# 新烧杯、试剂柜玻璃与重力过滤

## 烧杯

低型、中型、高型均为 **500 mL**，分别使用桌面原模型、原贴图。低型替换原 500mL 烧杯（旧内部 ID beaker_100ml）；新增 beaker_medium、beaker_tall。旧 250/1000/2000mL 烧杯保留 ID 和容量，沿用新低型外形，避免破坏旧存档。

手持有20档液位，放置后显示连续液位与沉淀。瓶口、点选和已有承载设备同步适配；三款均能放入试剂柜。

## 试剂柜玻璃

柜体和门框使用不透明绘制，玻璃单独绘制在柜内物品之后，并关闭玻璃层的深度写入，避免挡住柜内半透明物品；保持原色调、门动画和原版平滑光照采样。矮柜原来的实心百叶门仍是原设计，透明玻璃主要位于高柜上半部。

## 安装与使用

1. 创造模式仪器栏取出过滤漏斗、滤纸，放置一座**空铁架台**。
2. 拿过滤漏斗右键铁架台，模型自带夹具，不需要再放铁圈。
3. 拿滤纸右键漏斗，加入滤纸。
4. 拿空烧杯或锥形瓶右键装置，装配下方接收容器；也可对准下方安装已有液体的未封口容器。
5. 拿含液体与沉淀的容器右键漏斗上部，每次倒入最多25mL混合物；漏斗暂存容量100mL。
6. 有接收空间时自动过滤；实际出液才显示滴液粒子，接收瓶液位随之增长。

建议首个实验：水＋溶解的NaCl＋草酸钙沉淀。水和溶解NaCl通过，草酸钙留在纸上。

## 分离与容量

- 使用容器中已经记录的液态/固态成分；溶解物随滤液通过，固体留在滤纸。第一阶段没有胶体粒径分级。
- 滤渣最多20g，越多过滤越慢；无滤渣时每4tick最多处理1mL液体，20tick/秒下约5mL/秒。
- 湿滤渣按每克固体保留约0.2mL母液，最多5mL，所含溶解物一起保留。母液来自原混合物，不会凭空增加。
- 接收瓶满、被取走或封口时暂停；不用滤纸时直接导流，固体也会进入接收容器。
- 装置中的物质量是真实存储，滤渣厚度和漏斗液面为近似外观。

## 拆卸、换纸与回收

- 空手对准**下方**：取出接收容器。
- 空手对准**上方**：取出滤纸与湿滤渣，并自动暂停；放入新滤纸后继续。暂停且无滤纸时，再空手点上方可明确恢复无过滤导流。
- 潜行空手对准上方：整套取回，待滤物、滤纸、滤渣与接收瓶保存在漏斗物品内。再次装到铁架台会还原。
- 拿带滤渣的滤纸右键放置的容器，或另一只手拿容器、使用滤纸，可转移滤渣和残液。容量不足时只转移能容纳的部分，余量留在纸上。
- 破坏铁架台会掉落保存内容的漏斗；区块卸载不掉落。正常拆装时建议先取接收瓶再取漏斗。

本阶段为重力过滤，不包含抽滤、滤饼洗涤置换、干燥或粒径模拟。化学平衡另见方案，尚未扩展实现。
