# 滴定管与统一热量机制（2026-09-28）

## 滴定管
桌面五款模型全部加入：酸式玻璃旋塞、碱式玻璃珠、无色 PTFE、棕色玻璃旋塞、棕色 PTFE。容量均暂定 50 mL；五款共享取用规则，目前没有按酸碱或溶剂类型限制材质兼容性。

1. 手持滴定管右键空的实体铁架台安装。
2. 手持有液体的容器点击管身，每次转入最多 25 mL，液体内溶质按比例转移，保留来源中的固体。也可通过现有试剂取用方式加入。
3. 手持接收容器点击滴定管下方，安装接收容器。可以使用已有烧杯或锥形瓶。
4. 空手点旋塞开关；开启后每 4 个游戏刻滴入 0.05 mL。潜行点旋塞关闭连续流并滴一滴。最后不足一滴的液体按实际余量转移。
5. 接收容器满、密封、缺失或滴定管已空时自动停流，不扣除无法转入的液体。
6. 空手点下方取回接收容器；潜行点管身取下整套滴定装置，保留余量、接收液和累计滴加量。点击关闭状态的管身可归零累计读数。补液也会归零。
7. 护目镜显示实际余量、刻度、累计滴加量及接收液信息。接收液沿用现有酸碱平衡与实验反馈机制。

管身刻度是从额定 50 mL 起算，部分装液需记录初始与结束刻度的差，或查看累计滴加量。渲染液位连续变化，物品栏分 20 档；累计表目前保留浮点同步精度。碱式玻璃珠管使用相同开关操作，玻璃珠没有单独挤压动画。没有新增指示剂或自动识别终点。

配方：无色玻璃旋塞用玻璃与铁粒；碱式用玻璃与黏液球；PTFE 款用玻璃与石英；棕色款由对应无色款与棕色染料合成。这些是暂定游戏配方。

## 下一阶段：统一热量机制
新增以焦耳为单位的共用热量预算，供加热、环境冷却、溶解、中和、液体混合、晶体熔化/凝固、水汽化/凝结使用。

- 中和热按实际反应摩尔数计算：强酸与强碱室温近似 57.9 kJ/mol，乙酸与强碱近似 56.1 kJ/mol；同一份已中和物料不会再次放热。
- 现有已标定溶解热按实际溶解克数计入；未标定的物质没有猜测新增精确数据。
- 液体转移携带显热并计入接收容器热容量，过滤及各仪器的公用倒液路径已接入；原始 addMass 仍是内部物料记账接口，不假定每次调用都代表加入冷试剂。
- 晶体到熔点后先消耗/释放潜热，部分相变温度不变，相变完成后余下热量继续改变温度。修正旧的每次强制限制相变质量所导致的能量丢失。
- 敞口含水容器暂按 100°C 沸点处理，额外热量保存在汽化预算里，以 2256 J/g 兑换实际水汽；蒸馏接收端满或密封时不扣源液或汽化预算。
- 水蒸气统一使用 25°C 参考气体体积换算，凝结按相同换算还原水质量并放出潜热；敞口逸出仍会损失气体，不属于封闭守恒实验。
- 钠、钾、锂及部分氢化物与水的旧危险估算热量统一使用实际反应量，并移除按反应描述固定升温的重复路径。

### 适用范围
容器热容量、非水比热、多数晶体潜热、金属与水反应热仍为明确的游戏近似参数；铜熔化潜热使用 205 J/g。尚未建立完整反应焓数据库、所有气液相变、冰水相变、压力相关沸点、溶液沸点升高、热损失的实测动力学。密封容器压力与爆裂仍沿用既有游戏规则。电解仍沿用原先的升温修复，没有在此阶段加入全部电功与焦耳热。

酸碱 Kw/Ka、沉淀 Ksp 仍是既有 25°C 近似；统一热量不代表已支持这些平衡常数随温度变化。下一步按已有路线推进有机液体分层与基础分离，再逐步补有机反应、电化学及相平衡。
