# 铁—硫氰酸根配合平衡（第二阶段）

## 已实现

`Fe³⁺ + SCN⁻ ⇌ [FeSCN]²⁺`

- 在水中溶解氯化铁与硫氰酸钾，可得到带红色的配合体系。氯化铁溶液也可以直接使用现有试剂瓶。
- 根据溶解总量和实际液体体积求平衡；增加反应物促进配合，加水稀释使配合物部分解离，浓度下降时颜色变浅。
- 氯离子、钾离子保留为旁观离子，元素、总质量、电荷守恒。
- 配合物参与护目镜物种显示；手持物品染色及放置容器液色使用同一计算入口。层板中的容器仍使用其现有物品模型。
- 倒液、蒸馏、干燥残留、再溶解与存档读取从当前总量重算。干燥时不继续显示水溶液配合物；残留暂按原始盐类成分处理。
- 删除了原先直接生成 Fe(SCN)₃ 固体的血红色配方，避免旧引擎与平衡重复消耗反应物。

## 游戏中试用

1. 在烧杯、试管或锥形瓶中放水。
2. 加入少量氯化铁和硫氰酸钾，等待溶解；或先用氯化铁溶液，再加入硫氰酸钾。
3. 看液色变化，佩戴化学护目镜并潜行查看物种，能看到游离 Fe³⁺、SCN⁻ 和 [FeSCN]²⁺ 的量。
4. 加水后红色会变浅；补加少量试剂会增加配合量。原有工具一次取样量较大时，颜色容易饱和，可使用更大容量烧杯稀释。

## 数据与适用范围

`chem_contents` 仍是唯一物质量来源，保存溶解组分的总克数。`SolutionSpecies.analyticalSnapshot` 提供结合前总量，`snapshot` 提供当前平衡物种。配合比例是即时导出值，没有额外存一份可被重复扣除或复制的配合物库存。

`CoordinationEquilibrium.solve` 使用有界二分求解 `K(A-x)(B-x)=xV`，以摩尔和升为单位，避免超额结合与二次公式相消误差。已结合的输入会先还原总量，因此重复求解不累加产物。未知成分保留原质量。

这是 **室温、单级 1:1、浓度近似平衡**：Kc=113 L/mol，以教学演示在 20°C 的近似数值为参考。未引入活度系数、多级配合、水解、酸碱平衡、竞争配体、配合热或温度依赖。本阶段没有启用铜氨、银氨，也没有声称旧配方都已经按游离离子浓度计算速率。

氯化铁与硫氰酸钾的溶解上限暂分别采用 80、200 g/100 g 水的游戏参数，在 0–100°C 范围固定；不是实测温度曲线。本阶段不猜测这两者的溶解焓。干燥后的复杂盐类分配也需要后续固相平衡扩展。
