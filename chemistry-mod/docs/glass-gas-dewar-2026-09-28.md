# 集气瓶、玻璃与新试管更新（2026-09-28）

## 本次修复

- 集气瓶物品缩小至与试剂瓶相同的界面缩放；补齐空瓶原先引用但不存在的模型。空瓶、开口、盖板和装水外观均使用新模型。
- 集气瓶可以在方块顶面的点击位置摆放，朝向随玩家角度，同一方块可摆多个，分别点选，重叠位置拒绝放置。
- 自由摆放后仍可插玻璃导管、连接湿橡胶管、开关玻璃片、翻转与取回。端口按瓶子的实体标识区分，避免同一格里的多个瓶子串气；旧存档中唯一一只瓶子的旧端口会迁移。
- 按排空气法摆放装气瓶时，比空气轻的气体自动倒置。空瓶可用潜行空手右键翻转后集气；方向不合适时拒收气体。
- 装水的瓶子保持倒置，允许排水法收集轻、重气体，气体增加多少，水量减少多少。原有水槽排水集气操作保留。
- 拾取保留真实气体、水量、玻璃片和标签，不会把少量气体重新变成 250 mL。倒置且插导管时留出下方接管空间。
- 修复柜体、瓶身与其他半透明物体分开绘制造成的透视遗漏：玻璃与玻璃物品使用同一个主画面目标，透明部分不写入深度。柜体和沉淀仍正常遮挡背景。

## 模型和材质

- 新普通试管：桌面“实验室试管_A_普通玻璃试管.bbmodel”。
- 新杜瓦试管：桌面“杜瓦试管_收细版.bbmodel”。
- 普通试管替换原模型；杜瓦试管新增 50、100、250 mL 三种容量，与原试管容量一致，并包含试管夹、硼硅玻璃、一孔/二孔塞变体。
- 适配铁架台各个倾角、试管架正置/倒置、手持与物品栏，物品液位按容量分 20 档。
- 蒸馏头上的温度计套管横向宽度对齐蒸馏头顶端磨口，插入温度计的尺寸独立保留。
- 石棉网直接绘制为金属编织网、浅色陶瓷中心与暗色边框，物品图标同步更新。
- 液体加入轻微动态水纹、透明度和液面变化；沉淀单独保持不透明。采用原版风格，不是光线追踪或折射着色器。
- 本次没有使用图像生成技能。

## 杜瓦试管保温

环境升降温速度设为普通试管的 1/8，这是游戏用的统一系数。低于室温时缓慢回暖，高于室温时缓慢降温；不改变反应生成/消耗的实际热量和物态变化的潜热规则。

手持、试管架与铁架台均应用保温。铁架台上的试管改为连续加热/冷却，点灯不会瞬间跳到 600°C，灭灯也不会瞬间归零到室温；杜瓦加热更慢。

在创造栏可找到三种容量及配件变体。基础杜瓦试管可用对应普通试管与 7 块玻璃合成：上排“玻璃、空、玻璃”，中排“玻璃、试管、玻璃”，下排三个玻璃；配件仍沿用现有装卸方式。

## 操作提示

- 集气瓶右键方块顶面放置，按点击位置与玩家朝向摆放。
- 潜行空手右键已放置集气瓶：翻转。
- 普通空手右键：先拆导管，再拆玻璃片，最后拿起瓶子。
- 放置新测试包时，替换旧 MChemistry 模组文件，避免同时放两份。
